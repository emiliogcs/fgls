fgls

fgls estimates linear regressions by feasible generalized least squares when the errors are serially correlated, heteroskedastic of unknown form, or both:

  • Serial correlation (Perron and González-Coya, 2026). An AR filter is estimated from a Durbin regression, with its order chosen by BIC. This is consistent when the regressors are only pre-determined (they react to past shocks), where OLS and Cochrane-Orcutt are not. A variance estimator accounts for the estimated filter.
  • Heteroskedasticity of unknown form (González-Coya and Perron, 2024). An adaptive Lasso of the log squared residuals on candidate covariates gives the weights, and a bias-corrected sandwich variance keeps inference valid when the variance model is wrong. If nothing is selected, FGLS equals OLS.
  • Both together (Supplement S-4 of the 2026 paper).

It is the R counterpart of the Python package pyfgls, and agrees with it to machine precision on deterministic quantities. More code by the author: https://emiliogcs.com/code/.

Installation

# development version
# install.packages("pak")
pak::pak("emiliogcs/fgls")
# from CRAN, once released
install.packages("fgls")

Serial correlation with a non-exogenous regressor

library(fgls)
sim <- simulate_serial(500, seed = 1) # design of Table 1 of the 2026 paper; true slope 1
fit <- serial_fgls(y ~ x, data = sim)
summary(fit)

Heteroskedasticity of unknown form

het <- simulate_hetero(200, skedastic = "log2", seed = 2)
fit_h <- lasso_fgls(y ~ x, data = het, seed = 1)
fit_h$skedastic$selected
#> [1] "log(x)" "cos(x)"
compare_fgls(OLS = lm(y ~ x, data = het), FGLS = fit_h)
#>          term statistic        OLS       FGLS
